## Why

Factories (`server/factories.ts`) are the only remaining scrap sink
(`FACTORY_BUILD_COST_SCRAP`, see [[ANU-022]]), and scrap otherwise only
arrives slowly via combat kills (`server/units.ts`'s `attackSuburb` credits
`scrap_value` per kill). Manually earning scrap through combat just to build
and observe extra factories is slow to iterate on. A debug action that
credits scrap directly removes that bottleneck during testing. Confirmed
with the user (AskUserQuestion) that this stays visible/unguarded rather than
env-gated — this is a solo-dev course prototype, not a shared deploy with
other real players to protect it from.

## Done when

- A new `debugAddScrap` client message (`server/protocol.ts`, parsed +
  dispatched in `server/index.ts`) credits +100 scrap to the sending
  player's `lobby_members` row, following the existing
  `UPDATE lobby_members SET scrap = scrap + ?` pattern (`server/units.ts`'s
  `creditScrap`), and triggers `sendEconomyToPlayer` so the sidebar updates.
- A button in the sidebar (`server/public/index.html` / `sidebar.js`) sends
  this message.
- `pnpm check` passes.

## Resolution

Added `ClientDebugAddScrap` (`type: "debugAddScrap"`) to `server/protocol.ts`'s
`ClientMessage` union and parser, dispatched in `server/index.ts` next to the
`startResearch` handler: credits a flat `DEBUG_ADD_SCRAP_AMOUNT` (100) to the
sender via a new `store.addScrap(lobbyId, playerId, amount)` (a plain
`UPDATE lobby_members SET scrap = scrap + ?`, same shape as `units.ts`'s
combat-kill `creditScrap` but unconditional), then calls
`sendEconomyToPlayer` so the sidebar scrap readout updates immediately. Added
a "+100 scrap (debug)" button next to the scrap readout in
`server/public/index.html`'s `#sidebar-economy`, wired in `sidebar.js`'s
`mountSidebar` to `send({ type: "debugAddScrap" })`, styled with a dashed
border in `style.css` so it reads as a dev affordance rather than a real game
action. Left unguarded (no env flag) per the user's explicit choice — this is
a solo-dev course prototype, not a shared deploy with other real players to
protect it from. `pnpm check` (221 tests) passes.
