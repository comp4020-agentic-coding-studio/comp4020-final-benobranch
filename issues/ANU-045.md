## Why

[[ANU-040]] replaced [[ANU-036]]'s whole-map blur/quantize filter with a
narrower effect scoped to `.suburb` in `server/public/map.css`:
`shape-rendering: crispEdges` plus a thicker `stroke-width: 3` boundary in
`var(--accent-dim)`/`var(--accent)`. User feedback on seeing it in the live
app: it looks bad and should just be removed, not iterated on again.

## Done when

- `.suburb`'s `shape-rendering: crispEdges` and the ANU-040 comment block in
  `server/public/map.css` are removed; suburb boundaries render as normal
  anti-aliased SVG strokes again.
- `pnpm check` still passes.

## Resolution

Removed `.suburb`'s `shape-rendering: crispEdges` and the ANU-040 comment
block explaining it from `server/public/map.css`. Suburb boundaries now
render as normal anti-aliased SVG strokes; the thicker `stroke-width: 3`
`var(--accent-dim)`/`var(--accent)` border styling (the "super visible"
part of ANU-040, independent of the pixelation itself) was left in place
since nothing asked for that to change. No spec referenced `crispEdges`.
`pnpm check` (221 tests) passes unchanged.

## Notes

Not reopening [[ANU-040]] since that issue's own "done when" (boundaries
pixelated, colors untouched) was met — this is a straight aesthetic call to
drop the effect entirely, not a bug in how ANU-040 implemented it.
